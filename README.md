# gakki

**AI 应用开发 · 数据分析**

把业务问题拆成能跑起来的系统 —— 从数据清洗、指标口径，到多 Agent 编排与检索。

## 项目

### 🏋️ [IRON MIND · AI 健身私教](https://github.com/Humble-moon/gakki-ai-fitness)

Multi-Agent 协作生成个性化训练计划，GraphRAG 做伤病推理，混合检索的知识问答带来源引用。
提供方安全审查独立于生成链路，四个 Agent 分工协作，LangGraph 状态图编排，全链路 SSE 流式输出。

`Python` · `LangGraph` · `FastAPI` · `Neo4j` · `PostgreSQL` · `Redis` · `Docker`

### 🖼️ [gakki-picture](https://github.com/Humble-moon/gakki-picture)

云图库项目 —— 图片上传、存储与管理。

`Vue` · `Java`
