### 关于我

把业务问题拆成能跑起来的系统 —— 从数据清洗、指标口径，到多 Agent 编排与检索。

比起"演示时好看"，我更在意拆开看还站不站得住：结论能不能复核、边界有没有写清、失败路径有没有兜底。

**现在在做**：多 Agent 协作的训练计划系统 · Agentic RAG 检索链路 · 训练数据的指标口径与归因。
